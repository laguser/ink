# Welcome to Ink

A place for thoughts. A blank page. A quiet machine.

---

This is your first document. Everything you write here is stored as plain Markdown — no formatting, no clutter, just words.

### Get started

Start typing. That's all.

- `⌘,` — Settings
- `⌘⇧E` — Export TXT
- `⌘⇧P` — Export PDF
- `⌘⇧M` — Export Markdown

Ink saves everything automatically. Every keystroke, every pause — preserved.
